# 多模块会话与助手脚本修复

原生模板曾在每个响应重发SSO Cookie，并将会话以upsert写回。前一模块的迟到响应可能覆盖新模块Cookie，或恢复已撤销的旧SID。现在仅新建或显式轮换SSO写Cookie；已存在会话只在内容实际改变时更新仍有效的行。撤销以删除服务器会话为准，不发送可能误清新登录的过期Cookie。

统一助手脚本原先存在文件却没有固定HTTP路由，新功能页的ES模块导入会404。新增精确公开脚本路由，不开放其他文件，不携带业务信息。

开发电脑隔离Linux完整core测试：1019通过、61跳过、218子断言通过；生成项目旧测试原先要求撤销响应发送Max-Age=0，与防竞态要求冲突，已改为不重写Cookie，并保留旧Cookie再次使用401及实时核权断言。新增三种迟到响应的真实存储ASGI回归和生成项目真实HTTP脚本依赖检查（该检查随生成项目实际运行，模板目录直接运行跳过）。quick_validate通过。未执行公司工作流或真实设备验收，不能据此宣称其他部署完成。
