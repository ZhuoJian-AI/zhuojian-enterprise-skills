# 同站点内嵌浏览器会话兼容

部分内嵌浏览器在 SSO 成功后不回传 None/Partitioned Cookie，业务页因此 401，平台外壳随后等待 ready 超时。该现象需按请求链实证，不能凭 UA 指定属性根因或判断所有手机必然失败。

候选 core 1.1.54 保留 1.1.53 的迟到响应保护，为同一服务器会话增补 host-only Lax Cookie，逐候选验证签名、有效存储和撤销状态，显式轮换撤销旧候选。业务实时授权链不变。补充通用排查、责任归属和逐应用、逐客户端验收说明。旧大段内联文档的 CSS 扫描加入等价边界约束，避免无花括号文本导致二次复杂度。

验证：Windows core tests 938 passed / 7 skipped / 210 subtests；Skill Creator quick_validate 通过。两份个人安装分别仅同步九项指定文件，保留其他本地修改和稳定版 1.1.51 元数据；各自 13 tests / 3 subtests 通过。版本元数据未伪装成正式发布。公共源码提交/PR、稳定分发和企业 Runtime 部署是不同状态，本 PR 不代表稳定包已发布或所有实际手机已验收。
