# 子系统主题与 SaaS 外壳衔接

日期：2026-09-18；候选 Skill 版本：`zhuojian-subsystem-builder` 1.1.12。

## 边界

- 子系统继续各用自己的页面布局和配色，只登记原有 `presentation.moduleNavigationTheme` 四个受控颜色令牌；不登记 CSS，不让子系统操纵 SaaS DOM。
- SaaS 仅在当前系统的模块横栏、顶部标题身份区和侧栏当前系统选中项复用令牌；通用操作、其他系统、业务 iframe 不跟随染色。无有效主题时安全回退。
- 嵌入业务页由 SaaS 去除外层灰底、重复边框、阴影和 16px 框架间距，业务内容边距由子系统自行控制。手机模块完整网格和现有权限边界不变。

## 验收与状态

- 源码与文档已在独立分支修改；运行时验证、PR、合并和稳定 Release 分别记录，不能将源码修改称为 Skill 已发布。
- 下游业务负责人下次发布前仍须核对服务器当前源码、真实页面配色、四令牌对比度及桌面/手机截图。Skill 更新不自动修改或部署三个业务子系统，也不变更授权。
