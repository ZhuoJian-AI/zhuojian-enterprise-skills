# 飓鹏首次候选恢复与财务/跟单交接

问题：首次候选健康但登记前契约验证失败时，Runtime原有awaiting_platform_registration门禁没有安全修复入口。

修复：默认门禁保持，仅显式精确SHA、无发布历史、实时SaaS模块404的初始候选可以沿原部署事务恢复；其他记录和未知结果失败关闭。从未登记版本标记并禁止当作健康回退点。

配套：登记finance/order两个精确Runtime/主机交接，不复制业务数据或凭据。

验证：新增4项恢复策略测试及原Runtime用例26通过、1项Windows跳过、23子断言；开发电脑隔离Linux容器全套pytest为1017通过、60跳过、215子断言（浏览器等环境相关跳过保持原记录）。精确Runtime/host目录解析的6种情形通过。此结果不是公司工作流全部通过的声明。

当前自有CI契约禁止新增GitHub Release资产。旧稳定包分发机制尚需适配，此次不使用GitHub资产作为测试或交付通道；交接Skill源文件提交不代表稳定更新通道已发布。受测Runtime工具按合并源码SHA与文件哈希在已授权主机单独安装，保留旧工具及部署事务。

本PR只发布Skill与受控恢复工具，不声称业务入口已验收；实际业务部署和普通员工SSO另列项目回执。
