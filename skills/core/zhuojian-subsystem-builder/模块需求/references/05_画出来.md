# 05 · 画出来

> 开工计划书里有**两张图必画**：一张架构图（这东西是什么）、每个页面一张线框（长什么样）。
> 这一段讲怎么画。写文档时读，不用给用户看。

---

## 🔴 第一条：不许用字符画

```
❌ ┌──────────────┐
   │  搜款号、名称  │
   └──────────────┘
```

**中文是全角、框线字符是半角，浏览器里必然错位。** 换个字体就散架。
`white-space:pre` 也救不了 —— 它只保住换行，保不住宽度。

**一律用 SVG。** 下面有可直接抄的骨架。

---

## 为什么必须画

**业务负责人不会读完三千字。** 他会看图，然后指着某处说「这里不对」——
这一句「不对」比他读完全文点头有价值得多。

**承接方拿到纯文字，会自己猜页面怎么排。** 而那些是业务判断：
「打开就是搜索框、光标已经在里面」的依据是「他在客户面前，多点一下都嫌慢」——
**这个场景承接方不在场，他猜不出来。**

# 一、架构图

## 骨架（照这个，别自己发挥）

```
上排    数据从哪来          1–3 个
          ↓
中间    模块本体            1 个，黑底
          ↓
下排    页面 / 入口         2–4 个 ＋ AI 旁路
          ↓
底部    产出去哪            0–1 条（没有就删）
```

**下排超过 4 个 = 这个模块该拆了。** 回去看槽 4 —— 大概率是把两件事塞进了一个模块。

## 颜色是有意义的，不要乱用

| 颜色 | 值 | 什么时候用 |
|---|---|---|
| 🔴 红框 | `#c0392b` | **现在缺的、阻塞的** —— 一眼能看出这图哪里是空的 |
| ⬛ 黑底 | `#12161b` | 模块本体，全图只有一个 |
| 🔵 蓝框 | `#2f6fd0` | 使用者天天用的页面 |
| ⬜ 灰框 | `#8a929c` | 别人维护的 / 权限窄的 / 不常用的 |
| 🟡 黄虚线 | `#b8860b` | **AI 那条旁路，永远画虚线** —— 虚线表示它不走页面 |
| 🟢 绿线 | `#1a7a4c` | 产出流向公司外面（客户、供应商、工厂） |

⚠️ **红色是这张图最大的价值。** 如果有阻塞级待定，红框会让人一眼看出
「这东西现在是空的」—— 比在文字里写十遍「开工前必须先拿到」都管用。

## 可直接抄的骨架

`templates/开工计划书模板.html` 里那段 `<svg viewBox="0 0 840 400">` 就是。
坐标已经调好，**改文字就行**，别动坐标。

**要加减框的话，记住这几个数：**

```
上排    y=20   h=58    一个框 w=188
中间    y=140  h=72    w=340，x=250（居中）
下排    y=286  h=76    框宽 188（AI 那个 170）
横向    左边距 20，右边距 20（到 820），框间距 22
```

**下排放 3 个页面 + AI**：`x = 20 / 230 / 440 / 650`（模板里就是）
**下排放 2 个页面 + AI**：`x = 60 / 290 / 560`，宽度可以放大到 200
**上排只有 1 个来源**：删掉右边那个，把左边那个挪到 `x=326`（居中）

## 箭头别指到框的角上

```
❌  L250,150   ← 250 是框的左边缘，箭头戳在角上
✅  L300,134   ← 落在上边缘内侧，看着才像"进去了"
```

**下排的箭头从中间框的底边（y=212）出发**，先垂直下到 `y=250`，再水平走到目标正上方，再下到 `y=282`。
模板里四条都是这个走法，照抄。

## 图下面那两行说明

```html
<div class="cap">
<b>红色</b>是现在缺的那一环 —— 那份表没进来，下面三个页面都是空的。<br>
<b>黄色虚线</b>那条 AI 旁路，答出来的必须和「一款椅子」页上一致，只能查不能改。
</div>
```

**只写两行**，解释这张图里最容易看错的两处。不要复述图上已经写着的东西。

# 二、页面线框

## 一个页面一组：左边图，右边理由

```html
<div class="sc2">
  <div class="ui-wrap"> …SVG… </div>
  <div>
    <div class="t">① 页面名</div>
    <ul>
      <li><strong>这么排</strong> —— 为什么</li>
    </ul>
  </div>
</div>
```

**右边 3–4 条，每条一个格式**：`这么排 —— 为什么`。

🔴 **「为什么」必须指得回访谈里的某一句业务事实。** 指不回去的删掉 —— 那是你自己的审美偏好，不是需求。

| ✅ 指得回去 | ❌ 指不回去 |
|---|---|
| 打开光标就在搜索框 —— **他在客户面前，多点一下都嫌慢**（槽 1） | 搜索框应该放在显眼位置 —— 这是常识不是需求 |
| 不放全部列表 —— **一两百款翻不动**（槽 3 拿到的规模） | 列表不好看 —— 好看不是验收条件 |
| 图放右边不放上面 —— **会把三个参数挤到折线以下**（连着槽 6） | 图片放右边更平衡 —— 审美 |

**四条里至少有一条标 🔴** —— 那是最容易做错的一条。没有最容易做错的，说明你没想清楚。

## 通用画法

- 外框：`<rect x="8" y="8" width="404" height="{{H-16}}" rx="3" fill="#fff" stroke="#d5dae1" stroke-width="1.2"/>`
- 字号：正文 12–14，标题 15.5，小注 10.5–11.5。**再小就看不清了**
- 颜色只用这几个：文字 `#12161b` / 次要 `#4a525c` / 灰 `#8a929c` / 边框 `#d5dae1` / 面板 `#f7f8fa`
- 强调色跟架构图同一套（蓝 `#2f6fd0`、红 `#c0392b`、黄 `#b8860b`）

⚠️ **中文文字宽度按「字号 × 字数」估**，别贴着右边缘放。
`x=30` 起、`font-size=14` 的一行中文，20 个字就到 310 了。

## 骨架 A · 搜索页

**要画出来的重点**：光标在框里（一根蓝竖线）、类别是按钮不是下拉、底部有更新时间。

```xml
     font-family="MiSans, PingFang SC, Microsoft YaHei, sans-serif">
  <rect x="8" y="8" width="404" height="252" rx="3" fill="#fff" stroke="#d5dae1" stroke-width="1.2"/>
  <!-- 搜索框：蓝边 + 一根竖线当光标 -->
  <rect x="36" y="46" width="348" height="46" rx="3" fill="#fff" stroke="#2f6fd0" stroke-width="1.8"/>
  <rect x="54" y="59" width="2" height="20" fill="#2f6fd0"/>
  <text x="66" y="76" font-size="14" fill="#8a929c">搜XX</text>
  <!-- 最近搜过：药丸 -->
  <text x="36" y="126" font-size="12" fill="#8a929c">刚才搜过</text>
  <rect x="100" y="111" width="78" height="24" rx="12" fill="#f2f4f7" stroke="#e0e4e9"/>
  <text x="139" y="127" font-size="12" fill="#4a525c" text-anchor="middle">XXX</text>
  <!-- 类别按钮：y=162 h=28，每个 46–54 宽，间距 6 -->
  <rect x="36" y="162" width="54" height="28" rx="3" fill="#fff" stroke="#d5dae1"/>
  <text x="63" y="181" font-size="12" fill="#4a525c" text-anchor="middle">类别</text>

```

## 骨架 B · 详情页

**要画出来的重点**：最重要那几样在最上面、**一条红虚线标出"以上不滚动就得看见"**、图在右边。

```xml
<svg class="ui" viewBox="0 0 420 300" …>
  <rect x="8" y="8" width="404" height="284" rx="3" fill="#fff" stroke="#d5dae1" stroke-width="1.2"/>
  <text x="30" y="42" font-size="13" fill="#8a929c">← 返回</text>
  <rect x="312" y="26" width="72" height="26" rx="3" fill="#12161b"/>
  <text x="348" y="44" font-size="12.5" fill="#fff" text-anchor="middle">主操作</text>
  <text x="30" y="76" font-size="15.5" font-weight="600" fill="#12161b">标题</text>
  <!-- 关键字段：标签灰、值黑加粗，一行一个 -->
  <text x="30" y="112" font-size="12.5" fill="#8a929c">字段</text>
  <text x="78" y="112" font-size="14.5" font-weight="600" fill="#12161b">值</text>
  <!-- 图占位 -->
  <rect x="292" y="88" width="92" height="92" rx="3" fill="#f7f8fa" stroke="#e0e4e9"/>
  <!-- 🔴 折线：这条是这张图的灵魂 -->
  <line x1="30" y1="200" x2="390" y2="200" stroke="#c0392b" stroke-width="1.2" stroke-dasharray="5 4"/>
  <text x="390" y="216" font-size="10.5" fill="#c0392b" text-anchor="end">↑ 这条线以上，不滚动就得全看见</text>
  <text x="30" y="272" font-size="11.5" fill="#8a929c">来源：X · 日期</text>
</svg>
```

🔴 **那条红虚线不能省。** 它把「什么算做成了」直接翻译成了一条可验的视觉要求 ——
承接方看一眼就知道哪些东西不能往下挤。

## 画完自检

- [ ] **一个字符画都没有**（没有 `┌ ─ │ └`）
- [ ] 架构图下排 ≤ 4 个框；超过就是模块该拆了
- [ ] 有阻塞级待定的话，**架构图里对应的框是红的**
- [ ] AI 那条旁路是**虚线**
- [ ] 每个页面线框配了 3–4 条理由，**每条指得回访谈里某一句**
- [ ] 至少一条标了 🔴（最容易做错的那条）
- [ ] 详情页有那条**红虚线**（如果有"什么不滚动就得看见"的要求）
- [ ] 所有文字 ≥ 10.5px
- [ ] 估过文字宽度，没有贴着右边缘的长句

**最后一句自检**：把图单独抽出来给一个没读文字的人看，**他能不能说出这东西是干什么的？**
不能，就是还没画对。
