# 可选的插件研发执行端接入

## 适用方式

本页供获权管理员 AI 在用户选择企业插件研发、或交付“同事仅通过插件即可开发部署”的服务器时使用。既有 Skill + SSH + Runtime 开发方式继续沿用；没有选择插件研发时，不安装本页服务，不因此阻塞 SSH 初始化或普通发布。同一服务器可支持两种方式，共用企业、Runtime 和原有业务系统，不重新签发 Runtime 登记凭据。

Skill 提供开发契约；SSH/Runtime 是直接维护入口；插件 OAuth 和服务端研发执行端共同提供另一条入口。安装 Skill、拥有“系统研发者”角色、Runtime `doctor` 成功、SSH 发布成功，分别只证明各自事实，不能互相替代。

## 职责

- 服务器获权管理员或管理员 AI：安装该 Runtime 的研发执行端、必要依赖、独立执行身份及 HTTPS 入口，完成机器登记并核对实际链路。这里的管理员职责不表示管理员网页已经具备一键安装按钮。
- SaaS：验证本人 OAuth、当前系统研发者角色、连接范围、租户/Runtime、工具及撤权，按实际登记派发请求。
- 企业管理员：按已确认人员职责配置“系统研发者”等角色；企业管理员身份本身不自动授予研发或全部业务权限。
- 开发者及其 AI：通过所选的获权入口完成开发、测试、发布和结果验收。插件不下发 root、SSH 私钥、Runtime 机器凭据或其他开发环境的访问档案。

## 已有 Runtime 的接入

复用本机 Runtime 身份，先盘点现有研发服务、版本、配置及工作区。已经安装且实际链路可用时直接沿用；更新限于本次受影响的执行端，不重建企业、不重跑整机初始化、不重发业务子系统。

当前执行端的权威实现和安装参数见 SaaS 仓库 [deploy/enterprise-development/README.md](https://github.com/ZhuoJian-AI/ai-platform/blob/main/deploy/enterprise-development/README.md)。管理员从已核验的源码/公司构建取得服务器 kit；按该版本的构建说明、`kit-manifest.json` 和安装器 `--help` 操作，不从本页猜测已发布下载地址或复制另一企业配置。执行包与客户端插件分别交付，安装独立开发 Skill 或业务插件不代表服务器已安装执行包。

接入时需要落实的结果：

- 准备实际需要的 Python 环境、kit 依赖、Git、专用执行用户及浏览器/系统库；Node/npm 按项目需要准备。模型仍由原宿主推理，执行端不新建模型循环。
- 核对 kit 的逐文件摘要，将代码安装到 root 维护的不可变版本目录；工作区、日志及用户 HOME 按执行身份设置，保留已有任务和配置。
- 使用 kit 自带安装器读取本机既有 Runtime 凭据，向 SaaS 登记并领取绑定该 Runtime 的派发材料；秘密仅保存在受保护配置，不交给同事或插件。
- 按主机现有 SSH/HTTPS 架构配置精确研发域名、证书及回环监听。标准 SSH 22 已通的主机无需为了插件改成 SSH/HTTPS 多路复用；安装器默认监听不能直接套到不同架构。保留现有 ACME、域名、Nginx、应用端口池及业务服务。
- 由 SaaS 真实发现该 Runtime 的执行入口，再用获权研发账号核对工具及链路。缺执行端、未登记、缺本人角色、连接范围不足和网络故障分别报告；不借其他企业的机器身份补齐。

管理员配置完成后，由所选宿主真实执行一次独立测试项目的文件读写、命令/依赖、测试、构建、Runtime 发布、平台登记和网页读回；核对实际退出码、运行提交及持久任务结果。验证普通角色拒绝、跨企业/Runtime 拒绝和撤权，不能把工具已列出、健康探针或成功创建工作区当作已经部署。只承诺某一宿主时按该宿主验收；同时承诺 Codex、WorkBuddy 时分别核验，不强制未选择的客户端或未涉及的业务流程。

测试使用独立项目及数据，保留既有系统。写请求结果未知时先查原请求/任务状态，不换编号重复执行。接入失败不改变现有 SSH 权限；只能在用户已经授权的 SSH 范围内继续独立开发，不能把 SSH 成果冒充插件调用成功。

## 初始化交接状态

分别说明服务器安装、SaaS 登记、本人角色/连接授权和客户端验收状态。例如“SSH 直接部署已验证；插件研发执行端未配置”，或“SSH 已验证；插件服务和登记已完成，WorkBuddy 实际发布待验”。未选择的方式写“未配置/本次未启用”，不作为另一方式的额外门槛。

本页和 Skill 的发布仅更新接入说明，不自动安装其他服务器的执行端、改变人员角色或部署旧系统。服务器配置与真实端到端验收须另按本次已授权目标完成并留证。
