# 独立 Skill 与研发通道

开发说明与普通员工业务插件分别安装。研发者从企业网页“系统研发”获取独立 `zhuojian-subsystem-builder`；已有独立安装继续通过原更新器更新，不要求重新接入业务账号。通用 Skill 不按公司复制；企业服务器、项目与数据通道按 Runtime 的 `enterpriseKey`/`runtimeId` 解析独立交接 Skill，见[企业交接自动同步](managed-handoff-skills.md)。

先读取本人真实身份、有效角色及获权工具目录。既有企业插件研发工具继续使用，具体执行能力由服务端核权；只有业务查询工具时不得报告服务器部署可用。企业管理员身份、Skill文件或插件名称本身都不授予研发权限。已有独立 SSH 开发授权时可继续使用原访问档案，不把服务器凭据写入插件或交给员工业务调用。

旧完整插件曾携带开发 Skill。升级为业务包前，研发者先补齐独立 Skill；宿主更新只替换该插件自身文件，不能清理用户其他独立 Skill、SSH 档案、企业登录、项目或业务数据。原配对、授权、安装及更新接口保持兼容；已缓存旧版本或未热刷新会话按真实宿主状态报告，不把说明修改当作客户端已完成迁移。

选择插件服务器开发时仍按[可选插件研发执行端](plugin-runtime-bootstrap.md)逐机核验；SSH直接部署与插件研发分别记录。Skill发布不改造其他服务器、不重发业务子系统、不修改人员授权。
