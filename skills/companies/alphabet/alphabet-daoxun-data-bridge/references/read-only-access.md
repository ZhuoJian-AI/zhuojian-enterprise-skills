# 只读接入与验收

当前 ECS 已保存专用 SQL Server 只读身份。仅通过 root-only 集成配置和应用受控 Secret 复用，不向负责人索要或展示密码。账号能够连接 `H_TRADE` 并执行所需 `SELECT`；它不依赖 Windows 管理员密码，也不能在前端或 SaaS Bridge 中出现。

## 首次只读检查

使用兼容 SQL Server 2008 R2 的驱动与参数；当前 `pymssql` 连接已用 TDS `7.0` 验收通过。先完成：

1. 连接目标数据库并读取 `SERVERPROPERTY('ProductVersion')`、`DB_NAME()` 和当前数据库用户。
2. 查询 `sys.tables`、`sys.columns`、主键、索引、视图和存储过程定义所需的只读元数据，建立字段字典。
3. 使用 `HAS_PERMS_BY_NAME` 或等价元数据确认 `SELECT` 范围，并确认没有为本项目新增写权限。
4. 只对负责人明确需要的数据执行有上限的参数化样例查询，例如 `TOP`、时间范围或唯一业务编号。
5. 记录表间关系、时间字段、状态值、金额/数量单位、软删除标记和组织范围；不能仅凭列名猜业务含义。

不得用任何写语句测试权限，也不得创建“临时表后删除”或开启事务后回滚。

## 应用侧约束

- 数据库连接设置短连接超时、查询超时和有限连接池，避免影响道讯生产系统。
- 所有筛选参数绑定，不拼接用户输入为 SQL。
- 默认限制行数；大屏、统计和导出使用有界分页或经过确认的聚合查询。
- 子系统服务端按 SaaS 当前员工权限再次过滤数据。数据库账号能看到什么，不等于员工都能看到什么。
- 如果业务定义需要补充字段、批注、收藏、预警规则或审批状态，把这些内容写入子系统自己的数据库，用稳定的道讯业务键关联。
- 道讯查询失败时显示数据源暂不可用，不用历史缓存冒充实时结果。

## 容器验收

最终验收必须从实际部署镜像执行，不能只依赖已经通过的临时容器测试。应用容器加入 `zhuojian-daoxun-readonly`，使用环境档案中的 Docker 私网入口；凭证从 Runtime 管理的 Secret 注入。验证成功后确认 ECS 公网地址没有新增数据库监听端口。

最小验收结果应包含：SQL Server 协议握手成功、账号认证成功、目标数据库正确、一个有界业务查询成功、写入能力未被本项目启用。
