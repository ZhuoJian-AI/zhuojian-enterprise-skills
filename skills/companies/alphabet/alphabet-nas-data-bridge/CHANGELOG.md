# Changelog

## 1.0.3 - 2026-09-29

- 更新 NAS 双隧道直连杭州及宿主机、最终 NAS 容器真实读取验收，保留共享 ACL 与正文不落云端的边界。
- 随包开机脚本只改两处目标 IP；原密钥文件名、用户、严格 host key 校验和自动重连逻辑不变。

## 1.0.2 - 2026-09-28

- 记录两台 Runtime 的杭州候选与源地址、真实企业键，保留历史 Runtime ID 和专用 Docker 私网边界。
- 迁移必须从 NAS 端建立并验证目标受限隧道；随包脚本在实际切换前继续指向源环境，NAS 原件不进入主机或 OSS 复制。

## 1.0.1 - 2026-09-21

- 明确 NAS 原件不进入 ECS、OSS 或临时预览缓存，只允许有界内存流与必要元数据。
- 区分共享技术账号权限和员工权限，不自动开放部门目录，不提供上传或写回。

## 1.0.0 - 2026-09-11

- 登记 Alphabet 群晖 NAS 到两台企业 ECS 的受限反向隧道拓扑。
- 固化宿主机和 Docker 私网入口、凭证位置、共享访问范围与只读操作边界。
- 提供群晖开机启动及断线自动重连脚本。
